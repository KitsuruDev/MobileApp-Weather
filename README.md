# Приложение погоды

Многофункциональное погодное приложение для Android, созданное на языке **Kotlin** с использованием **Jetpack Compose**. Приложение предоставляет обновления погоды в реальном времени, подробные прогнозы, сервисы на основе геолокации и умные уведомления.



## Функционал:
- **Текущая погода:** температура в реальном времени, ощущаемая температура, скорость ветра, влажность, давление, видимость, время восхода и заката.
- **Прогнозы:**
    - Почасовой прогноз на 24 часа с горизонтальной прокруткой;
    - Прогноз на 7 дней с мин/макс температурой и вероятностью осадков.
- **Геолокации:** 
    - Интеграция с GPS с настройками высокой/экономичной точности;
    - Логика резервного выбора города (последний открытый -> избранное -> по умолчанию);
    - Обнаружение перемещения между городами.
- **Поиск и избранное:** 
    - Поиск городов с автодополнением (задержка ввода) и историей;
    - Сохранение до 10 избранных городов для быстрого переключения.
- **Детальная информация:** 
    - УФ-индекс;
    - Качество воздуха (AQI);
    - Фазы луны;
    - Интеграция карты осадков от Яндекса;
    - История погоды за 7 дней.
- **Умные уведомления:**
    - Ежедневный прогноз в выбранное пользователем время;
    - Предупреждения о плохих погодных условиях (грозы, экстремальные температуры, высокий УФ);
    - Уведомления об изменении погоды (падение/рост температуры, смена условий);
    - Оповещения о смене местоположения.
- **Кастомизация:** 
    - Полная локализация интерфейса (английский / русский) с его пересозданием;
    - Настройки единиц измерения;
    - 12/24-часовой формат времени;
    - Интервалы автообновления погоды (15, 30, 60 минут).


### Требования для запуска проекта
- Android Studio;
- Android SDK 34 (API level 34);
- Бесплатный API-ключ от [WeatherAPI](https://www.weatherapi.com/), который нужно указать в `com.example.appweather.network.WeatherApi.kt` (параметр `apiKey`)


### Запуск
1. Клонируйте репозиторий:
```bash
git clone https://github.com/KitsuruDev/MobileApp-Weather.git
```

2. Откройте проект в Android Studio.

3. Замените API-ключ.

4. Запустите приложение на эмуляторе или физическом устройстве, поддерживающем API level 34.
